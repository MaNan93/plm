# Version history

- Keep all version updates in `src/plm/docs/release_note.md`.
- Order version entries by release date, newest first. Add same-version changes
  to that version's entry with the change date.
- Record behavior changes, compatibility/migration instructions, and actual
  validation results. Distinguish local builds from separately committed releases.
- Update `src/plm/docs/release_note.md` for future versions; do not create
  per-version release-note files.

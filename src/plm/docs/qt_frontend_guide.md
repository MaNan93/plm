# PLM Qt 前端使用指南

Qt 前端编辑真实项目配置，并直接调用共享 PLM 核心生成 RTL 和 testbench。

## 启动与项目管理

在仓库的 `plm/` 目录执行：

```bash
uv sync --extra qt --locked
uv run python run.py -gui
```

安装包含 Qt 依赖的发行包后，也可以使用 `plm-gui` 或 `plm -gui`。
安装包不附带仓库中的示例项目；可从任意位置打开项目或新建项目。
源码启动会发现 `examples/<示例>/config/` 中的四套示例，也兼容已有旧 `test/`、
`configs/` 工作区。之前写死的仓库 `test/<示例>` 路径需改成 `examples/<示例>`。
自动测试的 `tests/fixtures/` 独立维护，不作为日常编辑项目。

主窗口默认尺寸为 1280 × 800，可拖拽调整；最小尺寸为 960 × 640。
侧边栏展开宽度固定为 260px，折叠为 56px，不提供拖拽调整。
项目标题旁显示保存状态与工作区路径；长路径自动省略，悬停查看完整路径。

侧边栏顶部有新建项目、打开项目、保存三个按钮。新建时填写项目名并选择父目录；
打开时可以选择项目根目录或其 `config/` 目录。项目行的右键菜单（或悬停时出现的
“更多”按钮）提供置顶、重命名、打开所在文件夹、重新加载、归档和删除。
置顶、归档和最近项目保存在本机 QSettings；项目名过长时显示省略号，悬停显示全名。
双击项目名称或选择菜单中的“重命名”可在原处编辑，回车或失焦确认，Esc 取消。
重命名、删除由项目服务修改实际目录。归档与删除后会重新选择可用项目；
没有可用项目时进入空状态：四个配置页仍可查看，但不能编辑，Generate 不可用。
删除只允许带 `.plm-workspace` 标记的工作区，并需要确认。

有未保存修改时，切换、重新加载或关闭窗口会提示保存、放弃或取消；归档当前
项目会先保存；删除项目只做一次删除确认，未保存的修改随项目一起丢弃。
保存不以校验通过为前提：表格里有不合法的格子也能存盘，校验结果照常显示，
生成时才要求配置合法。外部程序改动 CSV 或
`gen_flags.txt` 后，保存和生成会要求先重新加载，避免覆盖磁盘上的改动。

## 配置编辑

三个表格对应当前项目的三个 CSV。通过表格右键菜单添加行、删除当前行，
拖动整行可调整顺序，双击单元格直接编辑。编辑会实时校验：出错的单元格标红，
悬停显示原因；表格下方的红色摘要条显示第一条错误和错误总数，点击跳到出错的
单元格。生成时会再次执行完整的核心校验；保存不要求校验通过。

Controller 和 Signals 上方提供添加、复制、删除行按钮及搜索框。复制控制器时
分配新的空闲编号，并为控制器或信号名称添加唯一的 `_copy` 后缀。
搜索匹配任意列，显示匹配行数，不改变配置内容；过滤期间暂停拖动排序。
删除操作针对当前可见的选中行；添加或复制后清空过滤并定位到新行。
这些内容修改都支持撤销与重做。表头使用中文名称，悬停查看 CSV 字段名。

Controller 表格最大宽度为 800px；LaneMapping 和 Signals 使用可用内容区宽度，共用浅色网格线。
标题行保留底部分隔线，不显示上方和左右外框；数据区保留左右边线。
Controller 的三列等宽，标题和单元格文字左对齐。较长表格在内部滚动。
表头与交替行使用当前深浅主题的中性色阶。
Signals 的 `signal_type` 和 `direction` 静止时只显示当前值；悬停时淡入
12px 的下拉微标，键盘聚焦时完整显示微标。
点击或按空格切换，方向键也可选择；悬停显示主题胶囊背景，使用 150 ms 颜色过渡，
水平内边距 10 px、垂直内边距 4 px。非法载入值仍保留并提示。
Signals 前三列左对齐，后三列右对齐；信号名列保留弹性伸展，初始最小宽度提高为 256 个设计像素。
进入文本编辑后继续使用单元格的左、右或居中对齐，避免文字横向跳动。

### Controllers

| 列 | 含义 |
|---|---|
| `ctrl_id` | 从 0 开始的连续整数 |
| `ctrl_name` | 控制器名称 |
| `max_width` | 控制器最多支持的 lane 数 |

### Lane Mapping

`mode` 从 0 开始连续编号；`lane0`、`lane1` 等单元格使用 `<ctrl_id>-<ctrl_lane>`。
例如 `1-0` 表示 controller 1 的 lane 0。表格上方每个 controller 有一个色块，
点击色块选中它作为画笔，再在表格里点击或拖过若干 lane，这些 lane 就分配给该
controller，controller lane 下标从 0 起依次编号；单元格里显示的数字是 controller
lane 下标，颜色表示所属 controller。双击单元格可以直接输入 `<ctrl_id>-<ctrl_lane>`。
通道数与控制器画笔位于同一工具栏；空间不足时画笔会换行。网格文字根据实际
背景及选中、悬停叠色选择黑色或白色，深浅主题均保持可读性。
“Num of Lanes”下拉框提供 x2、x4、x8、x16、x32；其他 lane 数的配置可以正常打开和
保存，其 lane 数会出现在下拉框里。新增的 mode 行使用下一个空闲的 mode 编号并复制
上一行的分配。删除 mode 或改变 lane 数后应重新检查分配关系。

### Pipe Signals

| 列 | 含义 |
|---|---|
| `signal_name` | PIPE 信号名称 |
| `signal_type` | `perlane` 或 `shared`；`shared` 只允许用于 `mac2phy` |
| `direction` | `mac2phy` 或 `phy2mac` |
| `width` | 信号位宽 |
| `safe_state` | 交接窗口中没有 owner 时的安全值，两个方向都生效 |
| `tie_off` | 从未分配到 PHY lane 的 controller lane 的固定值，仅对 `phy2mac` 生效；填整数，或填 `lane0` 表示跟随该 controller 最低编号 lane 的值 |

例如 `mac_phy_txelecidle` 的 `safe_state` 通常为 1；
`phy_mac_messagebus` 的 `safe_state` 与 `tie_off` 可以分别设置为 `0x50`。
`safe_state` 和 `tie_off` 接受十进制或带 `0x`、`0b`、`0o` 前缀的整数，不接受
`8'h50` 这类 Verilog 常量写法；其余数值列只接受十进制。

## 保存与生成

Generation 页提供以下参数：
表单按“硬件与架构”和“模块与命名”分组，最大宽度为 760px；窄窗口可纵向滚动。

| 参数 | 选择与联动 |
|---|---|
| `arch` | 用户选择 `original_pipe` / `serdes` |
| `pclk-mode` | 只读显示，由 `arch` 自动决定：`original_pipe` → `pclk_as_phy_output`，`serdes` → `pclk_as_phy_input` |
| `bus-type` | Connection 端口形式：`bus`（默认二维数组） / `flat`（一维向量）；控制器端口仍各自独立 |
| `dpr` | 两种 PCLK 模式都支持；同时决定选择方式：启用为 `sync`，不启用为 `comb` |
| `module_prefix` | 模块与 package 名前缀 |
| `file_prefix` | 全部生成 `.sv` 文件名前缀 |
| `macro_prefix` | 生成宏及对应仿真 define 的前缀 |

三个前缀非空且末尾缺少 `_` 时自动补齐，留空保留原名称。修改前缀会使输出过期，
重新生成时成套替换 RTL/TB，并清理旧文件名。

启用 DPR 是一次可撤销的编辑。磁盘上已存在的非法参数组合会保留并提示校验错误，
不会在加载时悄悄改写。PHY input 模式的 DPR 使用外部 `dpr_pclk` 输入和逐 lane
`dpr_rx_clk` 输出。

**保存**写入 `controllers.csv`、`lane_mapping.csv`、`pipe_signals.csv`
和 `gen_flags.txt`。**生成**先保存并使用同一组 `GenerationOptions` 调用核心，
在 staging 中生成并检查整套 RTL/TB，成功后更新输出。失败时保留旧输出；
具体错误与真实生成记录显示在底部日志面板。
日志默认隐藏，通过标题栏按钮展开。生成开始时自动展开，
生成失败时重新展开，成功后保持当前展开状态，由用户手动收起。
收起后不占用底部空间，再次展开恢复上次调整的高度；展开时仍可拖动分隔条。
展开和收起使用 200ms 动画，动画过程中再次点击可反向切换。

`gen_flags.txt` 只供 Qt 前端记住生成选择；CLI 不读取它，CLI 参数需要显式传入。
Verible 设置保存在本机，不写入这个项目文件。

Generate 按钮和输出状态固定在 Generation 页左下角，不随表单滚动。生成状态包括
请选择项目、尚未生成、输出已过期、输出已是最新、配置有误、配置已被外部修改、
生成中和生成失败。
状态同时检查配置、生成参数、格式化器身份与参数，以及输出文件内容。
单独保存不会让旧输出变成最新；撤销到匹配现有输出的配置会恢复最新状态。
输出被修改、删除或 manifest 损坏后会显示过期；重新生成可修复。
完整且最新的输出会跳过写盘。

输出位于项目根目录的 `rtl/` 与 `tb/`，包括 SystemVerilog、文件列表及
`manifest.json`。RTL 和 TB manifest 的 `generation_key` 相同，确认它们来自
同一配置和参数组合。

## 文件预览

点击标题栏上的 Artifacts 按钮显示或隐藏文件预览，面板从配置页右侧滑出。顶栏显示
相对项目根目录的路径（放不下时保留文件名尾部），
点击路径胶囊弹出真实 `rtl/`、`tb/` 文件树；选择文件后自动收起，不挤压代码区。
预览为只读，显示行号，长行可横向滚动；超过 200 KiB 的文件需在外部编辑器中打开。
普通 Verilog 代码预览启用语法高亮。

- 搜索按钮打开当前文件内搜索，支持向前、向后及循环查找。
- 刷新重新读取磁盘，并尽量保持当前项目中选中的文件。
- 链接按钮复制完整文件路径；可通过代码区右键菜单复制选中文字。
- 编辑按钮通过设置中配置的编辑器打开文件；侧边栏项目菜单里的“打开所在文件夹”打开项目目录。
- 展开按钮放大预览，再次点击还原；拖拽手柄可调整宽度。
- 工具按钮右对齐，最右侧的关闭按钮收起面板；面板较窄时，部分工具按钮移入带图标的“更多”菜单。
- 面板参考 GitHub 浅色文件视图：白色代码区、浅灰工具栏、灰色行号和语法高亮。
  文件树使用 Lucide 文件夹、RTL 文件、JSON 文件和文本文件图标，以及浅色层级竖线。
- 差异比较使用 GitHub 风格：删除行红色、新增行绿色、区块标题浅蓝色，
  行号栏显示旧/新源码行号并配上对应底色；退出比较恢复普通预览。
- 输出状态在 Generation 页和底部输出面板中查看；输出面板底部的状态条显示最近一次
  生成的结果，切换项目或开始新的生成时清空。

切换项目会清除旧预览。文件无法读取时显示原因，不保留旧文件内容。

## 设置与文档

设置页有“通用”和“工具”两个分页。默认编辑器在“通用”中设置，
可以带参数（如 `code -g`）；含空格的可执行文件路径直接填写即可。
外部编辑器和 Verible 设置保存在本机，重启后恢复。
标题栏的明暗主题按钮与“通用”页中的主题选择同步；主题切换不会保存其他未提交的
设置草稿。工具页按对齐、缩进、其它和全部分类，可跨分类搜索参数。
文档页分“使用入门”（本指南）、“配置文件”和“生成命令”三个分页，安装包中也可使用。
完整版本历史与迁移方法统一记录在随包附带的 [release_note.md](release_note.md)。

“工具”分页可浏览选择 `verible-verilog-format`；路径留空时自动查找。参数表可编辑
核心支持的对齐、缩进、布尔、整数和字符串参数。标着 `(default)` 的选项是 PLM 内置
预设（`DEFAULT_VERIBLE_FLAGS`），不是 Verible 自身的默认值；整数和字符串参数留空时
同样使用这套预设。修改后点击“保存设置”才会生效。
参数可按“对齐规则”“缩进规则”“其它参数”分类，也可选择“全部参数”；搜索会跨
分类匹配参数名。切换分类或过滤不会丢失已编辑的值，保存时同时写入隐藏参数。
悬停参数或控件可查看说明和 PLM 默认值。通用设置限制在 640px 范围内，
主题选择立即生效并单独自动保存，其余设置通过“保存设置”生效。

切到“效果预览”可并排编辑示例源码、查看真实 Verible 格式化结果。预览使用当前
尚未保存的工具路径和参数，编辑停止 250ms 后在后台更新，也可点击“更新预览”。
切换示例会替换左侧源码；预览不写入项目文件，也不自动保存设置。
工具缺失、参数错误、语法错误或超过 3 秒未完成时显示原因并清空旧结果；
交互预览的源码大小限制为 64 KiB，常规 RTL/TB 生成仍沿用原有格式化行为。

保存设置会立即重新检查输出状态，下次生成应用新参数。
显式指定的工具不可用时保留生成器原始排版，并在日志中说明。

## 快捷键与常见错误

| 快捷键 | 功能 |
|---|---|
| Ctrl+Z | 撤销配置编辑 |
| Ctrl+Y / Ctrl+Shift+Z | 重做 |
| Ctrl+F | 焦点在预览面板内时打开搜索 |
| Enter / F3 | 下一个匹配，末尾循环 |
| Shift+Enter / Shift+F3 | 上一个匹配，开头循环 |
| Esc | 收起文件树浮层或关闭预览搜索 |

打开、保存、新建没有快捷键，通过侧边栏按钮操作。

| 错误 | 检查项 |
|---|---|
| mode 不连续 | 改为 0、1、2 等连续编号 |
| ctrl_id 越界 | 控制器编号及 `max_width` |
| 同一 controller lane 被重复驱动 | 当前 mode 下的 lane 分配 |
| 驱动源跨 group | 同一 controller lane 的所有驱动源应在同一组 |
| 同一 PHY lane 在不同 mode 换 controller lane 下标 | 同一 owner 的 lane 下标保持一致 |
| PCLK 候选数大于 1 | 最低编号 owned lane 是否保持一致 |

出现错误时先看表格下方的错误摘要和单元格提示，再看底部输出面板，修正后重新生成。

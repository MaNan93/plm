# Qt 工作区布局调整（2026-10-15）

本次以 `docs/screenshots/2026-10-15/` 中的截图和设计方案为基线，
改善编辑入口、日志占用和表单密度。保留现有靛蓝主色、CSV 字段与 RTL/TB 生成语义。

## 实现

- 日志默认收起为 34px 状态条；点击或开始生成时展开，生成失败时重新展开。
  成功后不自动打断阅读，用户手动收起；再次展开恢复本窗口内上次调整的高度。
- 项目头部增加文件夹图标、保存状态与工作区路径。长路径省略，悬停显示全文。
- 配置页标签采用下划线选中态，标题、分组和说明使用 15px、14px、12px 层级，
  保持正文和数据表 13px，以及 32px 控件高度。
- Controller 和 Signals 提供添加、复制、删除、按任意列搜索及匹配行数。
  过滤不改变配置；过滤期间暂停拖动排序，删除针对可见选中行。
  复制时分配唯一控制器编号，并为名称生成不重名的 `_copy` 后缀。
  保留右键操作、实时校验、撤销与重做；中文表头悬停显示原 CSV 字段名。
- Controller 最大宽度 800px；Signals 和 LaneMapping 保留可用宽度及内部滚动。
  LaneMapping 通道数和画笔合并为一行工具栏，画笔在窄窗口自动换行。
- LaneMapping 使用较沉稳的六色调色板；按实际背景、选中和悬停的透明度叠色
  计算文字颜色，修复浅色网格数字偏淡。深色主题增加带蓝色倾向的表面层次。
- Generation 使用垂直的“硬件与架构”“模块与命名”卡片，最大宽度 760px，
  两组标签对齐，窄窗口允许换行和滚动；生成按钮继续固定在滚动区之外。
- 通用设置居中限制到 640px，增加说明文字和卡片，保存按钮跟随内容。
  Formatter 最大宽度 760px，可按对齐、缩进、其它、全部分类；搜索跨分类进行，
  切换分类保留编辑值，保存包含隐藏参数。
- 文档采用最大 800px 的可收缩阅读容器，解决固定宽度在 960px 窗口下溢出的问题。
  保留 Artifacts 的按需搜索、差异预览与工具栏；不增加新的嵌套卡片。

## 与提案的校准

方向值继续显示 `mac2phy/phy2mac`，明确 MAC 与 PHY 两端，不改成缺少参照端的
`in/out`。PCLK 仍由架构派生。主题颜色仍通过共享 tokens 和已优化的主题切换路径
更新，不采用提案中的固定亮度阈值或白字浅蓝按钮示例。

宽度统一为 Controller/文档 800px、Generation/Formatter 760px、通用设置 640px；
日志收起高度统一为 34px。表单卡片纵向排列，避免两个固定宽度卡片在窄窗口溢出。
不使用 Qt QSS 不支持的浏览器专用属性。

## 验证方式

新增交互回归覆盖搜索不改变内容、过滤后删除、复制编号和名称、撤销、跨分类
参数保存、日志默认状态与高度恢复、失败时展开、窄窗口文档宽度，以及两种主题下
LaneMapping 选中/悬停叠色后的文字对比度。

性能通过 `scripts/profile_themes.py` 在原生 Windows Qt 环境复测。
全量 377 项测试：375 通过，2 项可选 Verilator 仿真跳过；新增交互回归 8 项通过。
Ruff F/E9 与 `git diff --check` 通过。原生 Windows Qt 5.15.2、1280 × 800、
缩放比 1.0 下六次交替切换主题，完整帧耗时中位数分别为：主界面 82.860 ms、
通用设置 85.249 ms、工具设置 181.768 ms、文档 147.096 ms。
原始数据见 [主题切换基准](benchmarks/ui_redesign_theme_switch_2026-10-15.json)。
截图通过 `scripts/capture_ui.py` 生成，包含深浅主题、主要分页、菜单、弹窗、
搜索和 960 × 640 窗口。正式截图在推送代码后保存至 `docs/screenshot/`。
